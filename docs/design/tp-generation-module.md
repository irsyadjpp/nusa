# SECTION 1 — Executive Summary

## Why TP Generation Module Design Matters

A well-designed TP generation module ensures:
- Structured representation of teaching plans as TP Sets
- AI-powered generation from curriculum CPs
- Clear approval workflow for teaching plans
- Complete audit trail for compliance
- Version tracking for curriculum updates
- Efficient search and retrieval of teaching plans

## TP Generation Flow

```
CP (Capaian Pembelajaran)
  ↓
TP Set Generation (AI-powered)
  ↓
Review (Teacher/School Admin)
  ↓
Approval (School Admin)
  ↓
Official TP Set
```

**Description**:
- **CP**: Learning Outcome from curriculum
- **TP Set**: Collection of TP Items for a CP, representing one AI generation session
- **TP Item**: Individual teaching plan within a TP Set
- **Review**: Teacher or School Admin reviews generated TP Set
- **Approval**: School Admin approves TP Set to become official

## Core Principles

- **TP Set as First-Class Entity**: TP Set is the primary entity, not individual TPs
- **AI-Generated**: TP Sets are generated by AI from CPs
- **Approval Required**: AI-generated TP Sets require explicit approval before becoming official
- **Version Tracking**: TP Sets are versioned per CP
- **Audit Trail**: Complete traceability from CP to TP Set to AI generation log
- **MVP-Focused**: Synchronous AI generation for MVP

# SECTION 2 — TP Set Design

## TP Set Entity

### TP Set Table

| Field | Type | Constraints | Description |
|-------|------|-------------|-------------|
| `id` | UUID | PRIMARY KEY | Unique TP Set identifier |
| `cp_id` | UUID | NOT NULL, FOREIGN KEY → cp(id) | Associated CP |
| `version_no` | INTEGER | NOT NULL | Version number for this CP |
| `status` | VARCHAR(20) | NOT NULL | Workflow status |
| `generation_source` | VARCHAR(50) | NOT NULL | Source of generation (AI_GENERATED, MANUAL) |
| `generation_reason` | TEXT | NULLABLE | Reason for generation |
| `generated_by` | UUID | NOT NULL, FOREIGN KEY → users(id) | User who generated TP Set |
| `ai_generation_id` | UUID | NULLABLE, FOREIGN KEY → ai_generation_logs(id) | AI generation log reference |
| `approved_by` | UUID | NULLABLE, FOREIGN KEY → users(id) | User who approved TP Set |
| `approved_at` | TIMESTAMP WITH TIME ZONE | NULLABLE | Approval timestamp |
| `created_at` | TIMESTAMP WITH TIME ZONE | NOT NULL, DEFAULT NOW() | Creation timestamp |
| `updated_at` | TIMESTAMP WITH TIME ZONE | NOT NULL, DEFAULT NOW() | Last update timestamp |

### Constraints

```sql
-- CP and version uniqueness
CREATE UNIQUE INDEX idx_tp_sets_cp_version ON tp_sets(cp_id, version_no);

-- Status index
CREATE INDEX idx_tp_sets_status ON tp_sets(status);

-- AI generation index
CREATE INDEX idx_tp_sets_ai_generation_id ON tp_sets(ai_generation_id);

-- Generated by index
CREATE INDEX idx_tp_sets_generated_by ON tp_sets(generated_by);

-- Approved by index
CREATE INDEX idx_tp_sets_approved_by ON tp_sets(approved_by);

-- Check constraint for status
ALTER TABLE tp_sets ADD CONSTRAINT chk_tp_sets_status 
CHECK (status IN ('DRAFT', 'UNDER_REVIEW', 'APPROVED', 'REJECTED', 'ARCHIVED'));

-- Check constraint for generation source
ALTER TABLE tp_sets ADD CONSTRAINT chk_tp_sets_generation_source 
CHECK (generation_source IN ('AI_GENERATED', 'MANUAL'));
```

## TP Item Entity

### TP Table

| Field | Type | Constraints | Description |
|-------|------|-------------|-------------|
| `id` | UUID | PRIMARY KEY | Unique TP identifier |
| `tp_set_id` | UUID | NOT NULL, FOREIGN KEY → tp_sets(id) ON DELETE CASCADE | Parent TP Set |
| `sequence_number` | INTEGER | NOT NULL | Sequence within TP Set |
| `title` | VARCHAR(500) | NOT NULL | TP title |
| `learning_objectives` | TEXT[] | NOT NULL | Learning objectives |
| `estimated_weeks` | INTEGER | NOT NULL | Estimated duration in weeks |
| `prerequisites` | UUID[] | NULLABLE | Prerequisite TP IDs |
| `status` | VARCHAR(20) | NOT NULL | Workflow status (inherited from TP Set) |
| `created_at` | TIMESTAMP WITH TIME ZONE | NOT NULL, DEFAULT NOW() | Creation timestamp |
| `updated_at` | TIMESTAMP WITH TIME ZONE | NOT NULL, DEFAULT NOW() | Last update timestamp |

### Constraints

```sql
-- TP Set and sequence uniqueness
CREATE UNIQUE INDEX idx_tp_tp_set_sequence ON tp(tp_set_id, sequence_number);

-- Status index
CREATE INDEX idx_tp_status ON tp(status);

-- Prerequisites index
CREATE INDEX idx_tp_prerequisites ON tp USING GIN(prerequisites);

-- Check constraint for status
ALTER TABLE tp ADD CONSTRAINT chk_tp_status 
CHECK (status IN ('DRAFT', 'UNDER_REVIEW', 'APPROVED', 'REJECTED', 'ARCHIVED'));

-- Check constraint for estimated weeks
ALTER TABLE tp ADD CONSTRAINT chk_tp_estimated_weeks 
CHECK (estimated_weeks > 0 AND estimated_weeks <= 52);
```

### Service

```go
func (s *service) GenerateTPSet(ctx context.Context, userID string, cpID string, req GenerateTPSetRequest) (*TPSet, error) {
    // Get CP
    cp, err := s.curriculumRepo.GetCP(ctx, cpID)
    if err != nil {
        if errors.Is(err, curriculum.ErrNotFound) {
            return nil, ErrCPNotFound
        }
        return nil, err
    }
    
    // Build AI prompt
    prompt := s.buildPrompt(cp, req.Preferences)
    
    // Call AI gateway
    aiResponse, err := s.aiGateway.Generate(ctx, prompt)
    if err != nil {
        return nil, fmt.Errorf("AI generation failed: %w", err)
    }
    
    // Start transaction
    tx, err := s.repo.BeginTx(ctx)
    if err != nil {
        return nil, err
    }
    defer tx.Rollback()
    
    // Create AI generation log
    genLog := &AIGenerationLog{
        ID:              uuid.New().String(),
        UserID:          userID,
        SchoolID:        cp.SchoolID,
        ArtifactType:    "tp_set",
        Provider:        aiResponse.Provider,
        Model:           aiResponse.Model,
        TokensUsed:      aiResponse.TokensUsed,
        EstimatedCost:   aiResponse.EstimatedCost,
        ResponseTimeMs:  aiResponse.ResponseTimeMs,
        Status:          "COMPLETED",
        PromptSnapshot:  prompt,
        ResponseSnapshot: aiResponse.RawResponse,
    }
    
    if err := s.aiRepo.CreateAIGenerationLog(ctx, genLog); err != nil {
        return nil, err
    }
    
    // Get next version number for this CP
    versionNo, err := s.repo.GetNextVersionNo(ctx, cpID)
    if err != nil {
        return nil, err
    }
    
    // Create TP Set
    tpSet := &TPSet{
        ID:               uuid.New().String(),
        CPID:             cpID,
        VersionNo:        versionNo,
        Status:           "DRAFT",
        GenerationSource: "AI_GENERATED",
        GeneratedBy:      userID,
        AIGenerationID:   &genLog.ID,
    }
    
    if err := s.repo.CreateTPSet(ctx, tpSet); err != nil {
        return nil, err
    }
    
    // Create TP Items
    for i, tpData := range aiResponse.TPs {
        tp := &TP{
            ID:                uuid.New().String(),
            TPSetID:           tpSet.ID,
            SequenceNumber:    i + 1,
            Title:             tpData.Title,
            LearningObjectives: tpData.LearningObjectives,
            EstimatedWeeks:    tpData.EstimatedWeeks,
            Prerequisites:     tpData.Prerequisites,
            Status:            "DRAFT",
        }
        
        if err := s.repo.CreateTP(ctx, tp); err != nil {
            return nil, err
        }
    }
    
    // Commit transaction
    if err := tx.Commit(); err != nil {
        return nil, err
    }
    
    return tpSet, nil
}

func (s *service) buildPrompt(cp *CP, preferences map[string]interface{}) string {
    prompt := fmt.Sprintf(`
Generate a Teaching Plan (TP) Set for the following Learning Outcome (CP):

CP Code: %s
CP Text: %s
CP Text (English): %s

Preferences:
- Duration: %v weeks
- Focus Areas: %v

Generate 3-5 TP Items with:
1. Sequence number
2. Title
3. Learning objectives (2-4 per TP)
4. Estimated duration in weeks
5. Prerequisites (TP sequence numbers)

Return as JSON array.
`, cp.Code, cp.Text, cp.TextEn, preferences["duration_weeks"], preferences["focus_areas"])
    
    return prompt
}
```

func (s *service) RegenerateTPSet(ctx context.Context, userID string, tpSetID string, req RegenerateTPSetRequest) (*TPSet, error) {
    // Get existing TP Set
    tpSet, err := s.repo.GetTPSet(ctx, tpSetID)
    if err != nil {
        if errors.Is(err, ErrNotFound) {
            return nil, ErrTPSetNotFound
        }
        return nil, err
    }
    
    // Check if TP Set can be regenerated
    if tpSet.Status == "APPROVED" {
        return nil, ErrCannotRegenerateApproved
    }
    
    // Get CP
    cp, err := s.curriculumRepo.GetCP(ctx, tpSet.CPID)
    if err != nil {
        return nil, err
    }
    
    // Build AI prompt
    prompt := s.buildPrompt(cp, req.Preferences)
    
    // Call AI gateway
    aiResponse, err := s.aiGateway.Generate(ctx, prompt)
    if err != nil {
        return nil, fmt.Errorf("AI generation failed: %w", err)
    }
    
    // Start transaction
    tx, err := s.repo.BeginTx(ctx)
    if err != nil {
        return nil, err
    }
    defer tx.Rollback()
    
    // Create AI generation log
    genLog := &AIGenerationLog{
        ID:              uuid.New().String(),
        UserID:          userID,
        SchoolID:        cp.SchoolID,
        ArtifactType:    "tp_set",
        Provider:        aiResponse.Provider,
        Model:           aiResponse.Model,
        TokensUsed:      aiResponse.TokensUsed,
        EstimatedCost:   aiResponse.EstimatedCost,
        ResponseTimeMs:  aiResponse.ResponseTimeMs,
        Status:          "COMPLETED",
        PromptSnapshot:  prompt,
        ResponseSnapshot: aiResponse.RawResponse,
    }
    
    if err := s.aiRepo.CreateAIGenerationLog(ctx, genLog); err != nil {
        return nil, err
    }
    
    // Get next version number
    versionNo := tpSet.VersionNo + 1
    
    // Create new TP Set
    newTPSet := &TPSet{
        ID:               uuid.New().String(),
        CPID:             cpID,
        VersionNo:        versionNo,
        Status:           "DRAFT",
        GenerationSource: "AI_GENERATED",
        GeneratedBy:      userID,
        AIGenerationID:   &genLog.ID,
    }
    
    if err := s.repo.CreateTPSet(ctx, newTPSet); err != nil {
        return nil, err
    }
    
    // Create TP Items
    for i, tpData := range aiResponse.TPs {
        tp := &TP{
            ID:                uuid.New().String(),
            TPSetID:           newTPSet.ID,
            SequenceNumber:    i + 1,
            Title:             tpData.Title,
            LearningObjectives: tpData.LearningObjectives,
            EstimatedWeeks:    tpData.EstimatedWeeks,
            Prerequisites:     tpData.Prerequisites,
            Status:            "DRAFT",
        }
        
        if err := s.repo.CreateTP(ctx, tp); err != nil {
            return nil, err
        }
    }
    
    // Commit transaction
    if err := tx.Commit(); err != nil {
        return nil, err
    }
    
    return newTPSet, nil
}

func (s *service) ApproveTPSet(ctx context.Context, userID string, tpSetID string, req ApproveTPSetRequest) error {
    // Get TP Set
    tpSet, err := s.repo.GetTPSet(ctx, tpSetID)
    if err != nil {
        if errors.Is(err, ErrNotFound) {
            return ErrTPSetNotFound
        }
        return err
    }
    
    // Check if TP Set can be approved
    if tpSet.Status != "DRAFT" && tpSet.Status != "UNDER_REVIEW" {
        return ErrInvalidStatusForApproval
    }
    
    // Update TP Set
    tpSet.Status = "APPROVED"
    tpSet.ApprovedBy = &userID
    now := time.Now()
    tpSet.ApprovedAt = &now
    
    if err := s.repo.UpdateTPSet(ctx, tpSet); err != nil {
        return err
    }
    
    // Create workflow history
    history := &WorkflowHistory{
        ID:          uuid.New().String(),
        ArtifactID:  tpSet.ID,
        ArtifactType: "tp_set",
        Action:      "APPROVE",
        UserID:      userID,
        Reason:      req.Reason,
        CreatedAt:   time.Now(),
    }
    
    if err := s.workflowRepo.CreateHistory(ctx, history); err != nil {
        return err
    }
    
    return nil
}

# SECTION 7 — Versioning Rules

## Version Tracking

### Version Numbering

**Rule**: TP Sets are versioned per CP.

**Implementation**:
- First TP Set for a CP has version_no = 1
- Each subsequent TP Set increments version_no by 1
- Version numbers are unique per CP (cp_id, version_no)

### Version Status

**Rule**: Only one TP Set per CP can be APPROVED at any time.

**Implementation**:
- When a TP Set is approved, previous APPROVED TP Sets for the same CP become ARCHIVED
- DRAFT and UNDER_REVIEW TP Sets can coexist with APPROVED TP Sets

### Version Comparison

**Rule**: Users can compare different versions of TP Sets.

**Implementation** (Future):
- Diff view between versions
- Side-by-side comparison
- Change highlighting

# SECTION 11 — State Diagram

## TP Set State Transitions

```
┌─────────┐
│ DRAFT   │
└────┬────┘
     │
     │ (submit for review)
     ↓
┌─────────────┐
│UNDER_REVIEW │
└─────┬───────┘
      │
      ├─→ APPROVED (approve)
      │      ↓
      │   ┌─────────┐
      │   │ARCHIVED │
      │   └─────────┘
      │
      └─→ REJECTED (reject)
             ↓
         ┌─────────┐
         │ DRAFT   │ (edit and resubmit)
         └─────────┘
```

## State Definitions

| State | Description | Allowed Transitions |
|-------|-------------|---------------------|
| DRAFT | Initial state after AI generation | DRAFT → UNDER_REVIEW, DRAFT → ARCHIVED |
| UNDER_REVIEW | Submitted for review | UNDER_REVIEW → APPROVED, UNDER_REVIEW → REJECTED |
| APPROVED | Approved and official | APPROVED → ARCHIVED |
| REJECTED | Rejected during review | REJECTED → DRAFT |
| ARCHIVED | Historical reference | No transitions |

## State Transition Rules

| From | To | Trigger | Conditions |
|------|----|---------|------------|
| DRAFT | UNDER_REVIEW | User submits for review | TP Set has required fields |
| DRAFT | ARCHIVED | System or user action | New version approved |
| UNDER_REVIEW | APPROVED | School Admin approves | User has approval permissions |
| UNDER_REVIEW | REJECTED | School Admin rejects | Reviewer provides reason |
| APPROVED | ARCHIVED | System or user action | New version approved or period ended |
| REJECTED | DRAFT | User edits and resubmits | User makes changes |

## Forbidden Transitions

- DRAFT → APPROVED (must go through review)
- DRAFT → REJECTED (must go through review first)
- UNDER_REVIEW → ARCHIVED (must be approved or rejected first)
- APPROVED → DRAFT (regeneration creates new version)
- APPROVED → REJECTED (approved artifacts cannot be rejected)
- ARCHIVED → Any state (archived is terminal)
