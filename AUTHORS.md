## How to Add Yourself

Jika Anda telah berkontribusi pada proyek ini dan ingin ditambahkan ke daftar ini:

1. Fork repository
2. Tambahkan nama Anda di bagian yang sesuai
3. Format:
   ```markdown
   - **[Nama Anda]** - [Email/Link GitHub]
     - Role: [Peran Anda]
     - Contributions: [Deskripsi singkat kontribusi]
   ```
4. Buat pull request dengan title "docs: Add [nama] to AUTHORS.md"
